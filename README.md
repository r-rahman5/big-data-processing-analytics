# Big Data Processing & Analytics

## Overview

This project explores large-scale data processing and analytics using Apache Spark and PySpark. The objective was to analyse large datasets efficiently by leveraging distributed computing techniques, SQL-based analytics, graph processing, and real-time streaming.

The project demonstrates how modern big data technologies can be used to extract insights from large volumes of structured and semi-structured data.

## Technologies Used

- Python
- Apache Spark
- PySpark
- Spark SQL
- GraphFrames
- Structured Streaming

## Features

### Data Processing
- Loading and transforming large datasets using Spark DataFrames.
- Data cleaning and preprocessing at scale.
- Aggregation and filtering operations using Spark SQL.

### Temporal Analytics
- Analysis of hourly, daily and weekly trends.
- Window-based analytics for time-series exploration.
- Behavioural pattern identification.

### Graph Analytics
- Construction of graph representations from network datasets.
- Breadth-First Search (BFS) analysis.
- PageRank computation for measuring node importance.
- Investigation of connectivity and network structure.

### Real-Time Streaming
- Processing streaming data using Spark Structured Streaming.
- Stateful computations using watermarking.
- Fault tolerance through checkpointing mechanisms.

## Results

The project demonstrates how distributed data processing frameworks can efficiently analyse large-scale datasets while supporting advanced analytical techniques such as graph processing and streaming analytics.

Key outcomes include:
- Identification of temporal behavioural trends.
- Network connectivity analysis using graph algorithms.
- Real-time event monitoring through streaming pipelines.
